# Aster Vale client pack 2.0.0

Minecraft 26.3 / NeoForge 26.3.0.101 / KTZ Launcher 3.4.5 이상 / Java 25.

검증된 일반 배포 모드 29개, 이모트 32개와 기존 리소스팩·셰이더를 포함합니다. 기존 1.21.4 모드 목록을 새 승인 목록으로 교체하고 개인 월드·지도·웨이포인트·스크린샷과 설정은 보존합니다.

- 커스텀 모드 12개를 포팅하고 공개 모드 15개를 공식 26.3 버전으로 업데이트했습니다.
- KoreanPatch는 Hangul로 대체했습니다. 공식 MIT 소스 `d187081fdcb5c713c19470994f4562a9cef61fcc`를 NeoForge 26.3.0.101에서 컴파일하고, 정확한 해당 로더 버전만 호환 목록에 추가한 로컬 호환 빌드입니다. Java 기능 소스는 변경하지 않았습니다.
- ModernFix는 공식 26.3 파일이 없어 제외했습니다. Emotecraft의 새 필수 의존성 PlayerAnimationLib를 포함합니다.
- Lethal Company 이모트는 구형 음악 패킷만 새 Opus 형식으로 변환했습니다. 기존 동작·UUID/메타데이터·아이콘은 바이트가 같습니다. 나머지 31개 이모트는 원본과 같습니다.
- Better Leaves는 설치되지 않은 TwilightForest 전용 자산 47개만 제외했습니다. 유지한 4,670개 파일과 LICENSE는 원본과 같습니다.
- Nexo 리소스팩은 클라이언트팩에 중복 포함하지 않고 서버의 기존 자동 전송을 사용합니다.

검증 전용 모드, 유료 서버 플러그인 JAR, 플레이어 데이터베이스, 계정 정보와 서버 설정은 이 배포에 포함하지 않습니다.
