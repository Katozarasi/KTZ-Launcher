# KTZ Launcher 3.4.1

- 서버 선택 화면에 토켓몬이 표시되지 않던 문제를 수정했습니다.
- 토켓몬을 선택하면 Minecraft 1.21.1 / Fabric 0.18.4, 현재 모드 39개와 한국어 리소스팩을 설치하고 `1.224.237.11`로 접속합니다.
- 서버 목록의 표시 설정을 배포 데이터에서 읽도록 변경하여, 이후 서버 추가 시 런처를 다시 빌드하지 않아도 됩니다.
- 기존 에스터베일 선택과 로그인·설정·실행 흐름을 유지합니다.

기존 런처의 설정 → 런처 업데이트에서 업데이트를 확인하고 설치한 뒤 재시작해주세요. 자동 업데이트가 되지 않으면 `KTZ-Launcher-setup-3.4.1.exe`를 사용해주세요.

한국어·영어·일본어 패키지 화면에서 토켓몬 표시, 선택 저장, 홈 이동을 검사합니다. 실제 Minecraft 실행과 서버 입장 확인은 별도입니다.
