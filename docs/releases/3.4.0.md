# KTZ Launcher 3.4.0

## 새로워진 런처

- 어두운 테마와 둥근 카드 디자인으로 화면을 개편했어요.
- 상단에 홈 / 라이브러리 / 스킨 / 설정 / 지원 메뉴를 배치했어요.
- 홈에서 계정, 서버 상태, 실행 진행률과 새로운 소식을 확인할 수 있어요.
- 라이브러리에서 설치된 팩 버전, 라이브 패치와 메모리 설정을 확인할 수 있어요.
- 지원 메뉴에서 로그 열기, 오류 정보 복사와 파일 복구 도구를 쉽게 찾을 수 있어요.

## 스킨과 망토

- 현재 계정의 스킨을 앞·뒤로 미리 볼 수 있어요.
- 64×64 PNG 파일을 선택하고 클래식 / 슬림 체형으로 적용할 수 있어요.
- 기본 스킨 복원, 보유한 Java Edition 망토 선택·해제를 추가했어요.
- 계정 전체에 반영되는 변경이므로 확인창에서 적용을 눌러야 변경돼요.
- 게임 준비·실행 중 변경과 중복 요청을 차단해요.

## 유지되는 부분

- 기존 Microsoft 로그인, Java 관리, 모드팩 설치·검증과 PLAY 흐름을 유지해요.
- 개인 음성채팅, 외형 숨김, 쉐이더와 이모트 설정을 초기화하지 않아요.
- 이번 릴리스는 런처 업데이트예요. 서버·플러그인·모드팩 버전은 바꾸지 않았어요.

## 업데이트 방법

기존 설치형 런처는 새 버전을 확인·다운로드한 뒤 런처를 재시작하여 적용할 수 있어요. 자동 업데이트가 되지 않으면 아래 설치 파일을 사용해주세요.

- 설치형: `KTZ-Launcher-setup-3.4.0.exe`
- 설치 없이 실행: `KTZ-Launcher-portable-3.4.0.zip` 전체를 풀고 실행해주세요.

## 검증 범위

한국어·영어·일본어 UI, 스킨 요청·오류 처리, 중복 실행 방지 및 개인 설정 보존을 자동 검사했어요. 실제 로그인된 계정의 프로필·스킨 이미지·보유 망토 조회도 확인했어요. 개발 중 실제 계정의 외형은 임의로 바꾸지 않았으며, 실제 스킨 업로드·게임 안에서의 외형 반영은 별도 사용자 확인이 필요해요.
