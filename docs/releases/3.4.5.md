# KTZ Launcher 3.4.5

에스터베일을 Minecraft 26.3 / NeoForge 26.3.0.101 클라이언트팩 2.0.0으로 업데이트합니다.

- Minecraft 26.x에 필요한 Java 25를 자동 검색·설치합니다. 다운로드 해시와 설치된 Java 버전을 확인하며 기존 다른 서버의 Java 설정은 유지합니다.
- NeoForge 26.x의 공식 런타임을 서버별 공용 데이터 아래 자동 설치하고 새 실행 방식에 맞는 클래스 경로와 네이티브 라이브러리를 구성합니다.
- 서버 설정과 클라이언트팩의 Minecraft·로더 버전이 다르면 설치를 멈춰 잘못된 조합 실행을 방지합니다.
- 에스터베일 모드 29개와 이모트 32개를 갱신합니다. KoreanPatch는 Hangul로 대체하며, 구형 Lethal Company 음악은 새 Emotecraft가 재생하는 형식으로 변환했습니다.
- 기존 마이크·음량·외형 숨김·개인 설정·셰이더 선택을 보존합니다. 새 JSON 설정 키와 스키마는 유지하면서 기존 사용자 값을 병합합니다.
- 월드, 지도, 웨이포인트, 스크린샷과 사용자 추가 파일은 삭제하지 않습니다. Nexo 팩은 기존 서버 자동 전송을 사용합니다.

검증: Java 25 자동 설치/해시 검사, NeoForge 26 실행, 클라이언트팩 보존·롤백, 런처 실행 가드·데이터 경로·스킨 서비스 회귀검사를 통과했습니다. 29개 조합의 실제 게임 실행에서 리소스팩 활성 상태, 이모트 음악 디코드·오디오엔진 재생, 옷장 동작과 복사 월드 접속을 확인했습니다.
