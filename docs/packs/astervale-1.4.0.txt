에스터베일 클라이언트팩 1.4.0

Minecraft 1.21.4 / NeoForge 21.4.157을 유지하며, 에스터베일 후속작 Modrinth 구성을 KTZ의 에스터베일 항목에 적용합니다.

- 클라이언트 모드 29개, 관리 설정 18개, 리소스팩 6개, 셰이더 2개를 동기화합니다.
- UniversalShop 0.6.0: 토켓몬 스타일의 상품 카드, 금색 선택 표시, 분류·검색·수량 선택 화면을 적용합니다.
- 사용자 이모트 32개를 포함합니다. Lethal Company의 새 음악 저장 형식을 현재 Emotecraft 2.5.8이 읽을 수 있도록 변환했으며, 동작·아이콘·음표 181개와 재생 타이밍을 유지합니다.
- Emotecraft 2.5.8 KTZ 보완본: 이모트를 순서대로 읽어, 동시 목록 등록 중 일부 이모트가 간헐적으로 누락되는 문제를 수정합니다.
- 활성 리소스팩은 Modrinth 기준으로 구성하고 Complementary Reimagined r5.9.3을 기본 셰이더로 설정합니다. BSL도 포함합니다.
- 기존 관리 모드는 새 목록으로 교체합니다. 월드·스크린샷·지도와 음성 채팅 및 외형 숨김 개인 설정은 보존합니다.

적용: 에스터베일 게임을 종료하고 KTZ에서 에스터베일을 다시 실행하면 새 팩을 받습니다. 런처 프로그램 재설치는 필요하지 않습니다.
서버 프로그램·월드·플레이어 데이터는 이 클라이언트팩에 포함하지 않습니다. 서버 시작·재시작은 수행하지 않았습니다.

검증: 팩 SHA-256·파일 목록 대조, 기존 설정 보존 검사, NeoForge 전체 모드 구성 실행 및 상점 화면 검사, 이모트 32개 파싱과 실제 클라이언트 목록 등록을 확인했습니다. 실제 서버 접속·거래와 모든 이모트의 인게임 재생 검증은 별도입니다.
