# 에스터베일 9월 19일 업데이트

지난 공지 이후의 변경 사항을 정리했어요. 서버 변경은 다음 정상 서버 시작 후 적용되며, 런처 추가 패치 15는 게임을 종료한 뒤 KTZ에서 에스터베일을 다시 실행하면 받아요.

## 1. 새로운 전투 가호 4종

- **용기사의 가호**: 공격 적중 시 30% 확률로 용염을 쌓아요. 용염은 6초 동안 중첩당 매초 공격력의 5% 피해를 주며, 5중첩에서 공격력의 50%로 폭발해요. 폭발하면 3초간 받는 피해가 10% 감소해요.
- **황혼의 낙인**: 황혼의 칼날 일반 공격·무기 스킬로 출혈을 쌓아요. 10중첩에서 몹 최대 체력의 2%, 플레이어 최대 체력의 8%를 기본 피해로 줘요. 흡수 체력과 PvP 제한은 유지돼요.
- **낙제의 가호**: 공격 적중 시 5% 확률로 반경 20블록의 적이 받는 피해를 10초간 3% 늘려요. 재발동해도 수치가 중복되지 않고 시간만 갱신돼요.
- **검능아의 가호**: 기본 근접 공격 피해가 7.7% 증가해요.
- 가호 목록에 신규 아이콘·설명·보유 여부가 표시돼요. 새 가호의 일반 드롭·상점 획득처는 이번에 추가하지 않았어요.

**카토의 의견 #** 지속 피해, 특정 무기 연계, 범위 지원, 기본 공격 강화처럼 서로 다른 전투 선택지를 만들었어요. 가호 피해가 다른 가호를 계속 재발동시키는 연쇄 효과는 막았어요.

## 2. 아이스크림 생활 경험치 버프

| 등급 | 경험치 효과 | 지속시간 |
| --- | --- | --- |
| 일반 | 지정 생활 직업 +3% | 15분 |
| 고급 | 지정 생활 직업 +6% | 20분 |
| 희귀 | 지정 생활 직업 +10% | 25분 |
| 전설 | 모든 생활 직업 +15% | 25분 |
| 전설 상위 | 모든 생활 직업 +20% | 20분 |

- 카일라 상점에 아이스크림 11종을 추가했어요. 일반 5종은 **1,500골드**, 고급 아이스바 3종은 **4,000골드**, 고급 더블 스쿱 3종은 **4,500골드**예요. 희귀 이상은 상점에서 판매하지 않아요.
- 봉인된 보물상자에 아이스크림 보상을 총 **10%** 확률로 추가했어요. 희귀 5종은 각각 1.6%, 별사탕 소프트콘은 1.7%, 붕어빵 아이스크림은 0.3%예요. 기존 보상끼리의 상대 비율은 유지하고 합계는 100%→90%로 조정했어요.
- 아이스크림 효과는 한 번에 하나만 적용돼요. 다시 먹으면 효과가 교체되거나 지속시간이 초기화되며, 시간은 누적되지 않아요. 사망·재접속 시에도 남아 있는 효과와 만료 시각을 유지해요.

**카토의 의견 #** 생활 활동을 준비하는 재미와 보물상자의 보상 선택지를 늘렸어요. 여러 아이스크림을 겹쳐 경험치 효율이 과도하게 높아지지 않도록 중복 적용은 제한했어요.

## 3. 요리 재료 4종을 한 번에 2개씩 제작

| 제작물 | 이전 → 변경 | 변경 후 재료 |
| --- | --- | --- |
| 요리용 우유 | 1개 → 2개 | 우유 양동이 2개, 빈 양동이 2개 반환 |
| 버터 | 1개 → 2개 | 요리용 우유 4개 |
| 간장 | 1개 → 2개 | 콩 6개 + 유리병 2개 |
| 칠리 소스 | 1개 → 2개 | 고추 6개 + 설탕 2개 + 유리병 2개 |

제작 시간은 **10초 그대로**예요. 재료도 기존의 2배를 사용하며, 제작 경험치·골드 보상과 이미 등록한 제작 작업은 변경하지 않았어요.

**카토의 의견 #** 기본 재료를 반복해서 만드는 번거로움을 줄였어요. 재료 대비 생산량은 유지하고 한 번에 만드는 양만 늘렸어요.

## 4. 후원권 뽑기 소리를 줄였어요

사용 시작·추첨 진행·당첨 발표 효과음의 볼륨을 각각 **기존 대비 50%**로 낮췄어요. 보상 확률과 연출 순서는 그대로예요.

**카토의 의견 #** 뽑기 소리가 대화나 다른 게임 소리를 지나치게 가리지 않도록 조절했어요.

## 5. KTZ 자동 패치

UI 모드를 **0.8.53 → 0.8.54**, 누적 추가 패치를 **14 → 15**로 올렸어요. KTZ 3.3.6 이상에서 게임을 완전히 종료하고 다시 실행하면 적용돼요. 음성채팅·외형 숨김·쉐이더·이모트와 개인 설정은 이번 패치에서 변경하지 않아요.

**카토의 의견 #** 새 가호 화면을 별도 수동 설치 없이 받을 수 있도록 필요한 UI 파일만 갱신했어요.
